# Project vision

TriGuide AI is a phone-first navigation aid for people who are blind or have low vision. The phone camera, on-device models, spoken cues, and a **virtual** three-wheel robot all run on the handset.

The current build is a research and simulation shell:

- Live camera preview is real.
- Object detection is not implemented yet. The app does not invent obstacles.
- The robot on screen is a kinematic simulation. No chassis is connected, and none should be purchased for this phase.

A later phase can add MediaPipe (or another on-device model with a compatible license) and drive the virtual robot from those cues. A physical robot stays out of scope until the user explicitly asks.
